# Журнал изменений

## [0.1.0-alpha] — 2026-11-08

Первый предварительный релиз MIBoard — статической панели управления mihomo.

### Возможности

- Обзор трафика с графиком и рейтингами доменов, прокси и регионов.
- Сохранённые подключения, выбор прокси, сортировка узлов и проверка задержки.
- Соединения, анализ IP и доменов, правила маршрутизации и журналы ядра.
- Карта стран с локальной базой GeoIP без внешних запросов геолокации.
- Русский и английский интерфейс, светлая и тёмная темы, мобильная навигация.

### Установка

Релиз содержит `dist.zip` и контрольную сумму `dist.zip.sha256`.
Файлы панели находятся в корне архива, чтобы mihomo мог распаковать его
через `external-ui-url`. Для этой версии нужен адрес скачивания с тегом
`v0.1.0-alpha`: предварительные релизы не становятся `latest`.

### Статус версии

Это alpha-версия для первоначального тестирования. История трафика хранится
в памяти открытой вкладки; после обновления страницы сбор начинается заново.
Сохранённые подключения и настройки остаются в браузере.

Контракты API и сценарии интерфейса проверены с локальным mock-сервером.
Испытание этой alpha-версии с реальным ядром mihomo ещё требуется.
