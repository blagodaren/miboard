# Журнал изменений

## [0.1.3] — 2026-11-10

### Интерфейс

- README на русском и английском: скриншоты интерфейса, таблицы возможностей
  и загрузок, быстрый старт и отдельные подробные руководства.
- Диалоги соединений и диагностики приведены к общему ритму отступов по 4 px
  и согласованной типографике; подписи и JSON читаются при размере от 12 px.
- В настройках задержки мобильные поля увеличены до 44 px; внутренние отступы
  приведены к общим 16 px. Сохранены палитра, шрифты, логотип и расположение разделов.
- У выбора групп для замера и подробностей устройства появились явные стрелки
  раскрытия. Состояние блока видно до нажатия.
- Ссылки установки приложения открывают «Приложение и обслуживание»,
  ссылки истории — категорию «Данные» вместо первой категории настроек.

### Настройки и приложение

- Настройки разделены на пять категорий. Прямая ссылка открывает нужную категорию;
  переключение сохраняет несохранённые поля и предпросмотры.
- Размер карточек прокси и высота групп на широком экране настраиваются отдельно.
  Доступны большие и компактные карточки, компактные, высокие и неограниченные списки.
- Установка как PWA, открытие оболочки без сети и проверка обновлений. Новая сборка
  проверяется перед применением; открытая панель обновляется по кнопке.
  Отдельно показаны обновление текущей установки и новый релиз на GitHub.
- Синхронизация настроек через API хранилища ядра с предпросмотром и проверкой
  конфликтов. Адреса серверов, secret и история соединений в синхронизацию не входят.
  JSON-перенос настроек поддерживает новые параметры отображения и обновления данных.
- Единые уведомления о результатах действий и предупреждения об остатке трафика
  и сроке подписок. Предупреждения настраиваются отдельно для каждого сервера.

### Соединения и аналитика

- Расширенная таблица соединений и панель подробностей: адреса и порты,
  входящее подключение, процесс, DNS-режим, цепочки, правило, скорости и исходный JSON.
- Выбор активных или наблюдавшихся соединений за 1 час, 24 часа и 7 дней
  с учётом сохранённого журнала. Пропуски наблюдений и ограничения истории видны в интерфейсе.
- Аналитика по приложениям, сетям/ASN, входящим подключениям, протоколам
  и пользователям. Неизвестные данные сохраняются отдельной категорией.
- Экспорт доменов в TXT из аналитики, устройств и правил: весь отфильтрованный
  список, без ограничения видимыми строками, с удалением повторов и IP-адресов.
- Сводка трафика в боковой панели и сведения о памяти, сети, TUN и геобазах ядра
  в настройках. Отсутствующие значения не заменяются предполагаемыми.

### Прокси, правила и диагностика

- Отдельная вкладка провайдеров прокси: сведения о подписке, обновление и проверка,
  поиск, фильтрация и сортировка нод. Диагностика ноды показывает историю задержки
  по URL и сообщённые ядром возможности адаптера.
- Выбор групп для общего замера задержки с сохранением для каждого сервера.
  Ручные замеры остальных групп доступны независимо от этого выбора.
- Одноимённые ноды разных провайдеров проверяются отдельно; результаты не смешиваются.
  При неоднозначном составе группы проверку выполняет ядро, а индивидуальная
  диагностика позволяет выбрать провайдера явно.
- Провайдеры правил: просмотр состава и сведений, фильтрация и обновление.
  Для поддерживаемых ядер доступны статистика проверок и временное отключение правил
  с проверкой фактически применённого состояния.
- DNS-инспектор поддерживает дополнительные типы записей, включая PTR, и показывает
  секции ответа и флаги. DNS-ответы не используются для угадывания маршрута соединения.

### Надёжность и ограничения

- Потоки телеметрии восстанавливаются при зависании, обрыве сети и возвращении
  компьютера из сна. Запоздалые ответы прежнего подключения не меняют текущий сервер.
- Экономный режим приостанавливает сбор в скрытой вкладке и возобновляет при
  возвращении. Пропуски явно отмечаются; первый снимок после паузы не создаёт
  ложного скачка скорости. Непрерывный сбор остаётся режимом по умолчанию.
- История доступна только за время наблюдения подключённой панелью и ограничена
  настройками журнала. Объёмы выбранных соединений — счётчики за всё время их жизни,
  а не трафик строго внутри выбранного периода. PWA не добавляет фоновый сбор данных.
- Офлайн-кэш содержит только файлы панели. Ответы API, WebSocket и запросы с
  данными доступа не кэшируются. Метаданные PWA и контрольные суммы файлов
  проверяются при упаковке обеих сборок. Проверка релиза также отклоняет
  согласованный архив старой версии, если версия в `package.json` уже изменена.

### Установка

Два архива: `dist.zip` с локальными шрифтами и `dist-cdn-fonts.zip` со шрифтами CDN,
оба с контрольными суммами SHA-256. Для mihomo используется ссылка
`https://github.com/blagodaren/miboard/releases/download/v0.1.3/dist.zip`.
Сохранённые серверы и настройки предыдущей версии сохраняются в браузере.

## [0.1.2] — 2026-11-09

### Возможности

- Диагностика домена в «IP и домены»: ответы A/AAAA от DNS ядра, фактическое
  правило, цепочка прокси и адрес назначения из наблюдаемых соединений.
  При отсутствии наблюдений маршрут не угадывается по DNS.
- Журнал завершённых соединений: поиск по домену, устройству и прокси,
  подробности, страницы по 100 записей и хранение в браузере отдельно для каждого
  сервера. До 5 000 записей; срок хранения — 1 час, 24 часа, 7 дней или выключено.
- Проверка стабильности прокси: десять последовательных HTTP-замеров, медиана,
  p95, минимум/максимум и число сбоев. Серию можно остановить; отменённый запрос
  не считается ошибкой. Сбои HTTP не выдаются за потерю пакетов.
- Управление провайдерами прокси: обновление через API ядра, число нод,
  время обновления и сведения о подписке, если провайдер их передаёт.
- Перенос настроек через JSON: серверы, названия устройств, сортировка,
  параметры задержки, язык и тема. Secret исключён по умолчанию. Импорт
  показывает предпросмотр, сохраняет существующие данные доступа при отсутствии
  secret в файле и не переключает живое подключение.

### Изменения

- Проверка задержки следует логике zashboard: режимы ядра и панели,
  конечные ноды и провайдеры, ограничения параллельных запросов, отдельный
  IPv6-замер и независимая история по URL. Новые значения по умолчанию:
  режим панели, `https://www.gstatic.com/generate_204`, таймаут 5000 мс.
  Ранее сохранённые параметры остаются прежними.
- На узких экранах подписи графа правил открываются в читаемом масштабе;
  график трафика не повторяет подписи из-за делений короче секунды.
  Название прямого режима сокращено до «Прямой».
- Запись журнала защищена от запоздалых ответов старого сервера и ошибок
  хранилища. Импорт проверяет весь файл до записи и откатывает изменения
  при ошибке сохранения.

### Хранение и установка

Журнал фиксирует только соединения, замеченные открытой панелью. Разрыв связи
не считается завершением соединения; исчезновение после перерыва помечается
отдельно. По умолчанию записи хранятся 24 часа. Журнал и конфигурация mihomo
не включаются в экспорт настроек.

Доступны `dist.zip` с локальными шрифтами и `dist-cdn-fonts.zip` со шрифтами CDN,
оба с контрольными суммами SHA-256. Ссылка для mihomo:
`https://github.com/blagodaren/miboard/releases/download/v0.1.2/dist.zip`.
Версия публикуется без alpha-суффикса и становится `latest`.

## [0.1.1-alpha] — 2026-11-09

### Интерфейс

- Общий проход по десяти экранам: единый ритм отступов, читаемые подписи,
  спокойные числовые сводки и согласованные кнопки, поля и состояния выбора.
- Исправлена корневая шкала размеров Tailwind: мелкие подписи теперь 12 px,
  компактные кнопки — 32 px; сохранены Geist, графитовая палитра и янтарный акцент.
- Мобильные таблицы, журналы, настройки и графы используют доступную ширину;
  активная вкладка видна после открытия прямой ссылки и обновления страницы.
- При переходе в другой раздел страница открывается с заголовка, не наследуя
  положение прокрутки длинной таблицы или формы.
- Настройка уменьшения движения применяется ко всем анимациям и переходам.

### Возможности

- Экран устройств с активными соединениями, локальными названиями и графом
  «устройство → прокси → назначение».
- Распределение задержки по группам, сортировка узлов и единые статусы выбора
  прокси с обработкой частичных ошибок.
- Дополнительная аналитика правил и граф цепочек маршрутизации.
- Единая палитра обеих тем и документированный UI-кит.
- Встроенная GeoDB — DB-IP Country Lite; сравнительный отчёт с server-country
  и исходные снимки сохранены для воспроизводимой проверки.

- Поддержка дополнительных API Prizrak-Core: параметры Smart и LightGBM,
  веса узлов Smart-групп, очистка истории с подтверждением, обновление модели
  и смена узла для сайта из списка соединений.
- Автоматическое определение поддержки без зависимости от строки версии;
  дополнительные элементы скрыты при подключении к обычному mihomo.
- Параметры, которые API не позволяет изменять, отображаются только для чтения.

### Установка

Два архива: `dist.zip` с локальными шрифтами и `dist-cdn-fonts.zip` со шрифтами
CDN. Для каждого опубликована контрольная сумма SHA-256. Ссылка для mihomo:
`https://github.com/blagodaren/miboard/releases/download/v0.1.1-alpha/dist.zip`.

Предварительный релиз сохраняет статус alpha; API и интерфейс проверяются
с изолированными mock-серверами. История трафика собирается, пока открыта вкладка.

## [0.1.0-alpha] — 2026-11-08

Первый предварительный релиз MIBoard — статической панели управления mihomo.

### Возможности

- Обзор трафика с графиком и рейтингами доменов, прокси и регионов.
- Сохранённые подключения, выбор прокси, сортировка узлов и проверка задержки.
- Соединения, анализ IP и доменов, правила маршрутизации и журналы ядра.
- Карта стран с локальной базой GeoIP без внешних запросов геолокации.
- Русский и английский интерфейс, светлая и тёмная темы, мобильная навигация.

### Установка

Релиз содержит основной архив `dist.zip` с локальными шрифтами и дополнительный
`dist-cdn-fonts.zip` со шрифтами из `unpkg.com`. Для каждого архива есть свой
файл контрольной суммы `.sha256`.
Файлы панели находятся в корне каждого архива, чтобы mihomo мог распаковать его
через `external-ui-url`. Для этой версии нужен адрес скачивания с тегом
`v0.1.0-alpha`: предварительные релизы не становятся `latest`.

CDN-вариант загружает шрифты закреплённых версий; при недоступности CDN остаются
системные шрифты, цветные флаги на Windows могут быть недоступны.

### Статус версии

Это alpha-версия для первоначального тестирования. История трафика хранится
в памяти открытой вкладки; после обновления страницы сбор начинается заново.
Сохранённые подключения и настройки остаются в браузере.

Контракты API и сценарии интерфейса проверены с локальным mock-сервером.
Испытание этой alpha-версии с реальным ядром mihomo ещё требуется.
