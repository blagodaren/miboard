Map data: Natural Earth, version 5.1.2, Admin 0 countries (110m outlines,
50m country labels, and 50m/10m map-unit labels for small countries and
territories). Public domain. The UM marker uses the source's Wake Atoll label
as a representative point for the disconnected US Minor Outlying Islands.

Sources:
- https://github.com/nvkelso/natural-earth-vector/tree/v5.1.2/geojson
- https://www.naturalearthdata.com/about/terms-of-use/

Projection: Equal Earth, Bojan Šavrič et al. (2018), implemented by d3-geo.
https://d3js.org/d3-geo/cylindrical#geoEqualEarth

`equal-earth.json` is generated by `node scripts/generate-earth-map.mjs`.
The application uses only the generated SVG paths and points. No geographic
data, IP addresses, or host names are sent to an external mapping service.
