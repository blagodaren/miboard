# UI kit MIBoard

Цвета и размеры задаются в `src/app.css`. Компоненты используют семантические роли;
светлая и тёмная палитры описаны рядом через `light-dark()`. Выбор пользователя
и системная тема меняют `color-scheme`, а не набор локальных CSS-переопределений.

## Роли цветов

| Назначение | Токены / классы | Применение |
| --- | --- | --- |
| Основная панель | `card`, `line` | Карточка на фоне `page` |
| Вложенные детали | `raised`, `line` | Раскрытая строка, настройки внутри панели |
| Заголовок таблицы | `--table-head` | Единый фон всех `thead`, включая sticky |
| Текст | `fg`, `fg-2`, `fg-3` | Основной, вторичный, пояснение |
| Поле | `field`, `field-border` | Поиск, input, select, группа переключателей |
| Выбор | `selected`, `selected-border`, `selected-text` | Выбранная строка, вкладка, сегмент или карточка |
| Направления трафика | `traffic-down-ink`, `traffic-up-ink` | Загрузка янтарная, отдача нейтральная |
| Линии трафика | `--traffic-down`, `--traffic-up` | Янтарная сплошная и серая пунктирная линии |
| Успех / предупреждение | `good`, `warning` | Реальный статус, подпись или числовая задержка |
| Ошибка | `bad`, `bad-surface`, `bad-border` | Текст и блок сообщения об ошибке |
| Опасное действие | `bad-fill`, `on-bad` | Заливка и контрастный текст кнопки |
| Категории диаграмм | `--chart-*` | Разные категории данных; подписи остаются читаемыми |

Янтарный — единственный акцент интерфейса. Цвета категорий диаграмм, флаги стран
и настоящие логотипы сохраняют смысловую раскраску. Декоративные разноцветные иконки
и отдельная палитра для каждой страницы не используются.

## Общий шаблон

1. Заголовок страницы — `PageHeader`, 28px. Заголовок панели — 14/20px, вес 500, обычный регистр.
2. Панель — `rounded-panel` (16px), вложенная карточка — `rounded-card` (12px), поле — `rounded-control` (10px).
3. Внутренний отступ панели — 20px, на узком экране — 16px. Между секциями — 24px.
4. Кнопки — `Button`; действия диалога используют тот же `buttonClass()` из `src/lib/ui.ts`. Поиск и переключатели — общие компоненты.
5. Выбор обозначается фоном и границей, статус — текстом или значком вместе с цветом. Заливку графика нельзя использовать как цвет мелкого текста.

Переключатель сохраняет компактный трек 36×20px; прозрачная область нажатия вокруг него — 44×44px.

```svelte
<section class="rounded-panel border border-line bg-card p-4 sm:p-5">
  <h2 class="text-sm font-medium">Название панели</h2>
  <p class="mt-1 text-xs text-fg-3">Краткое пояснение</p>
  <div class="mt-4">...</div>
</section>
```

Размеры иконок: 16px в кнопках, 18px в заголовках, stroke 1.5.
Плотные таблицы и детальные показатели используют моноширинный шрифт;
числовые значения — табличные цифры.
Мелкие пояснения и подписи мобильной навигации — от 12px; компактные числовые метки диаграмм могут быть 11px.
При открытии ссылки или обновлении страницы выбранная мобильная вкладка остаётся видимой.
При переходе в другой раздел прокрутка страницы возвращается к заголовку; прокрутка самой полосы вкладок остаётся независимой.
При `prefers-reduced-motion: reduce` переходы и анимации отключаются во всём интерфейсе.

Диалоги подробностей используют заголовок 16/24px, секции 14/20px и шаг отступов 4px.
Подписи пиковых скоростей, провайдеров и исходный JSON — не меньше 12/20px,
включая телефон. Длинные значения переносятся внутри диалога.
В мобильных формах высота полей — не меньше 44px, отступ до края панели — 16px.
Раскрываемые блоки с собственным flex-заголовком показывают шеврон 16px:
он поворачивается при раскрытии и остаётся нейтральным по цвету.

Ссылки из контекстных подсказок ведут сразу к категории: журнал — `category=data`,
обновление приложения — `category=maintenance`. Пользователю не нужно повторно искать настройку.

Внизу настольного меню — `SidebarStats`: скорость и суммарный трафик в двух направлениях,
соединения, память ядра и график последней минуты. Загрузка — янтарная сплошная линия,
отдача — нейтральный пунктир. Панель использует существующие потоки ядра; до первого
кадра и при обрыве соответствующего потока вместо устаревших чисел показывается «—».
В невысоком окне прокручивается список разделов, выбранный пункт остаётся видимым.

## Подвкладки и детали провайдеров

На странице «Прокси» внутренние вкладки «Группы» и «Провайдеры» используют
`Tabs` из Bits UI: роли tab/tabpanel, стрелки клавиатуры и видимый фокус.
Выбор отражается в hash-параметре `tab`, поддерживает прямую ссылку и историю.
Настройки и раскрытые группы сохраняются при переключении; действия провайдеров
прекращают ожидание при уходе с их вкладки.

Подробности провайдера раскрываются внутри его панели. Длинный список нод
показывается по 50 строк; таблица прокручивается внутри панели на узком экране.
Нет данных о лимите или замере — это отдельное состояние, а не ноль или успех.

## Уведомления

Результаты действий и ошибки API показываются через общий `notifications.show()`:
стек справа снизу, не больше трёх видимых сообщений. Следующие ждут своей очереди.
Повтор с тем же `id` заменяет сообщение и начинает новый отсчёт 8 секунд.
Наведение, фокус клавиатуры и скрытая вкладка приостанавливают таймер;
закрыть сообщение можно кнопкой или Escape, когда фокус внутри него.

Поверхность использует `--notification-surface`: полупрозрачная карточка с размытием.
Текст и кнопки сохраняют полную непрозрачность. На мобильном стек расположен над
нижней навигацией с учётом safe area. При уменьшении прозрачности в настройках
системы используется сплошной фон. Валидация полей, загрузка и состояние данных
остаются рядом с соответствующим элементом, без дублирования результата действия.

## Установка и обновления приложения

`AppSettings` использует существующие панели, роли текста и `Button`:
версия, состояние обновления, установка и готовность открытия без сети.
В настройках это отдельный раздел; на экране серверов доступен тот же компонент.
Состояние остаётся в разделе после закрытия краткого уведомления.

Уведомление о загруженной сборке предлагает явное действие «Обновить и перезагрузить».
Новая версия не перезагружает интерфейс автоматически. Сообщение о релизе на GitHub
ведёт к релизу; оно не изображает обновление файлов чужой установки.
При недоступности HTTPS/localhost или режима PWA показывается конкретное пояснение,
а обычные функции панели сохраняются. Офлайн-готовность относится к интерфейсу,
а не к доступности ядра или актуальности его данных.

## Проверка изменений

```powershell
npm run check
npm run test:palette
npm run test:theme
```

Для `test:theme` нужен запущенный Vite. Проверка использует отдельный mock,
проходит все десять экранов в обеих темах на 1440/390/320px, измеряет контраст
текста и полей, проверяет выбор, фокус и диалог. Скриншоты и JSON-отчёт находятся
в `.theme-check/`. `test:palette` входит в `npm test` и обнаруживает локальные
цветовые литералы вне общей палитры; лицензированные изображения и данные карты исключены.
